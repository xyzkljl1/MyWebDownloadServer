# YoutubeDLServer
A simple program which receive url from YoutubeDLChromeExt and download pictures or videos.
Current module: anime1, cosplaytele,nhentai,telegra.ph,ytb-dlp sites,
# Prepare

Run Mysql server in localhost:4321,use create_table.sql to create table

Run YoutubeDLChromeExt
